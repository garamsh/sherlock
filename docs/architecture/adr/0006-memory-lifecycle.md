# ADR 0006: Memory lifecycle — curation-only, salience-tiered retention

> Status: accepted
> Date: 2026-07-25 (revised in place 2026-08-14; 2026-08-17; 2026-08-23)

## Context

The founding plan requires human-like memory: memories are refreshed, compressed, and forgotten, with the agent as the decision-maker. The original revision introduced platform auto-capture of every inbound message to make "remember X" reliable with a small chat model. A structured experiment (`docs/experiments/memory-architecture/`, 38 candidate architectures × four workloads: small, 10-year-horizon, eight-category diverse, 60k-item large-scale) measured what that decision actually does: auto-capture stores every turn at uniform low importance, and on every metric that matters — recall@5, precision@5, anti-pollution, memory density (recall per KB), scale stability — the architectures that auto-capture lose to the architectures that store only curated content. Against auto-capture itself there is no ratio to quote: A1 and A2 return 0.00 recall@5 on every run they appear in, bar 0.03 for A1 on the diverse workload. Against hybrid RAG reading the same auto-captured store, the curated architectures recall 1.1× to 2.7× as much, and their recall per KB is 12.5× to 523.0× higher across the runs where both were measured — a spread that moves with the workload and with which curated architecture is asked, so no single figure stands for it and the record carries the per-workload numbers behind it. The safety net was itself the pollution.

The same experiment identified the architecture that holds up on every workload: curation-only storage, a salience tier on every stored memory, salience-scaled Ebbinghaus decay, and tiered retention. This record revised the lifecycle to that shape, less the decay: it ordered eviction and nothing else, and a later record measured that ordering losing the class it is asked about (ADR 0018), so §Decision now carries the rule that replaced it. The prior art survey stands (MemGPT self-editing, Mem0's ADD/UPDATE/DELETE vocabulary, A-MEM/Mem0 write-time updates, Zep temporal invalidation, Generative Agents scoring) — the experiment adds the empirical ranking of the mechanisms.

That experiment also produced a mechanism this record no longer carries: supersession on insert, where an `add` whose content was highly similar to an active memory superseded it in place. No threshold separates a correction from two facts that must both survive — on all three embedders measured, the correction family's median similarity sits below the coexisting family's minimum, so the highest-accuracy threshold is the one that supersedes nothing (`docs/experiments/memory-creation/`, `docs/experiments/memory-retrieval/`). Removal rather than retuning was tracked in #334, and it waited on a replacement: ADR 0018 is that replacement, and it needs no threshold, because a fact is held at the address of the question it answers and identity is computed rather than inferred. The code stopped superseding ahead of that sequence: once a write carried its address in the sentence the store holds, the shared boilerplate lifted unrelated facts about one subject over the threshold and they destroyed each other (#529).

## Decision

Memory and context are separate stores connected by an automatic loop. Context is organized around the current task; long-term memory flows in and out of it each turn.

1. **Frame** — at each user request the agent articulates the current task in context. The task statement anchors what follows.
2. **Recall** — the runtime reads the memories held at the address the turn's question resolves to, and injects them. The step that resolves a question into an address is ADR 0018's read step, decided by ADR 0019 and built: the runtime wires it as the session's recall hook, and the turn reports the outcome it reached (`memory.md` §Current state). What replaced the hybrid-search query it used to run is not a better query: an addressed store answers nothing asked in words, which is the other face of identity being settled before the read rather than inferred during it (ADR 0018).
3. **Act** — the agent executes with the composed context. Accessed memories have `access_count` and `last_accessed` updated automatically.
4. **Writeback** — a turn ends by calling the reserved writeback tool, and its arguments are the document: the visible reply, and the list of facts the turn states. The list is a field of that document, never a block the model may omit, and an empty list is an answer it states. It travels as a tool rather than as a response format because a response format is a promise a provider can accept and ignore (#615), and because the session can refuse to end a turn without the call where it cannot refuse to accept prose. Each entry is an address, a value, and — where the sentence adds a value that leaves the question alone — an operation (ADR 0018).
5. **Write-time coherence is removed.** The step retrieved the most similar existing memories and presented them for the model's judgment, so related memories were corrected together instead of drifting into contradiction. That is what a store which could not compute which memory a write was for needed; ADR 0018's address computes it and the operation the write states says what to do about it, so the note has nothing left to ask. It went with the similarity read it was built on (#582).

Storage discipline (new):

- **Curation-only.** Only the writeback writes to the store. No platform auto-capture of inbound messages: no path stores a message at accept time. A message the model never states as a fact never enters long-term memory.
- **Salience is platform-derived, never model-written.** The contract does not ask the model for a score (the `importance_score` exclusion stands). The platform derives salience from the operation the write states: a replacement (a correction) is highest and a fact added beside what is held is high. There is no third tier, because there is no third operation and nothing else writes. Salience is set at insert time and read by the retention tiers below, and by nothing else.
- **Eviction orders by last read, and nothing is scored.** The capacity cap discards the least recently read first, counting a memory nothing has read as read longest ago (ADR 0018 §Forgetting is decided by use). What this replaces was a score of salience plus an Ebbinghaus decay whose half-life scaled with salience, which is an age-ordered rule under another name and loses every `carried` fact at the bound; its relevance term had already gone with the hybrid cosine and FTS5 blend it was made of, because an addressed read reaches its address without scoring anything.
- **Identity is not inferred from similarity.** No write path decides that one memory supersedes another by how alike their contents are. Which memory a write is for is settled by the address it computes, not by a threshold over a similarity score (ADR 0018).
- **Tiered retention.** After a completed turn, the runtime drops active memories by tier: high salience (≥ 0.6) is kept indefinitely; mid salience is retained for a bounded window of wall-clock time — 7 days from the memory's timestamp; low salience is dropped promptly. Nothing is hard-deleted — drops move to the archive. The window is elapsed time and not conversation, so it does not track how much has been said since: an agent taking a turn a day keeps a mid-salience memory for about seven turns, and an agent idle for longer than the window drops every mid-salience memory on the turn that ends the idleness, having taken none in between. Whether the window should instead run from a memory's last use is an open question in `memory.md`, and eviction moving to last use does not settle it: the eviction record measured which memory to discard once a bound bites and measured no retention window.
- **Eviction carries forward; consolidation does not.** The active-index capacity cap (ADR 0002) operates unchanged over the curated store, and retention makes it rarely binding. Threshold-triggered consolidation compressed episodic clusters, and an addressed store holds none: it is removed with the write that produced them (#582).
- **Context overflow no longer drains into memory.** When the conversation window fills the oldest turns leave it and nothing is written. The store holds an address and a value (ADR 0018), and a summary of a conversation answers no question a read can ask for — there is nowhere to put it. What this removes was already conditional and already off on the configuration this repository ships: the write was refused unless a model generated the summary, and the deterministic stand-in does not (ADR 0004: it stands in for a model's availability, never for its behavior), so an operator running without a real summarizer already stored no episodic memories at all. The curation rule the condition protected now holds by construction: compaction reaches no store.

Supersession semantics are unchanged in shape: a write that replaces what an address holds supersedes it rather than overwriting, and every change is reversible through the archive. What performs it is the write's own declaration at a computed address (ADR 0018), not an `Update` operation naming a memory ID — that operation had no statable caller and is removed (#582).

## Consequences

- The store holds only what the model judged worth keeping, so the noise floor is empty by construction, and recall per KB is 12.5× to 523.0× that of hybrid RAG reading an auto-captured store, depending on the workload and the architecture (`docs/experiments/memory-architecture/`). Against auto-capture's own retrieval there is no ratio: it returns nothing. **Precision did not follow from that emptiness**: measured against a store holding nothing but curated facts, the ranked read path returned mostly non-answers in its top ten, under either embedder (`docs/experiments/memory-retrieval/` §What the numbers say). That read path is gone — an addressed store returns the address it was asked for and nothing else — and the hybrid score's uncalibrated constants left with it (#582, ADR 0018 §Consequences). What the step in front of the store returns is its own to earn and is not measured.
- The model's failure mode inverts: a model that never writes back (issue #302) leaves memory empty, and that emptiness is honest — there is no safety net fabricating a store out of traffic. The reserved writeback tool removes the shape half of that failure — the document has no hole to leave the memory field in, and a turn does not end until it arrives — and leaves the content half, which is the model's willingness to state what it read. That residual is guided by the contract text and observable on the writeback event stream, where an empty list on a fact-rich turn is visible.
- Nothing in this lifecycle keeps the latest version of a fact authoritative. Curation decides what enters the store and retention decides what leaves it; which of two memories about one fact is current is a question this record no longer answers, and ADR 0018 is where it is answered.
- Salience decides the retention tiers and nothing else, and both tiers a write can state sit at or above the keep tier, so the retention pass drops nothing a writeback wrote (`memory.md`). What it used to decide beside them was eviction order, which is now read off what a read touched.
- ADR 0015's turn-drain guarantee rests on the terminal-event signal and the sender-resends philosophy, not on a memory backstop.
- The numbers behind the tiers and the window above are tunable constants, not architecture. `internal/memory/salience.go` declares them and is where their values are read; this record does not carry their names.

## Rejected alternatives

- **Auto-capture at uniform importance.** Measured to be the root of recall pollution; the safety net fabricates a store out of traffic and drowns curated content (`docs/experiments/memory-architecture/`).
- **Full-array sync each turn** (the model receives the store and returns it) — O(store size) tokens both ways per turn, omission becomes deletion, and LLMs cannot reproduce long lists verbatim. The writeback states only what the turn asserted, and the address it computes is what says where each value lands.
- **A writeback the model may omit** — the fenced block the contract asked for and nothing enforced. Measured at 0.00 context-recall with 0 of 15 responses emitting one voluntarily; shape-enforcement is the change that moves it, at no extra call (`docs/experiments/memory-cycle/`).
- **Automatic per-turn consolidation** — token cost and unpredictable recall degradation. Threshold triggers were the prior-art standard and were what this record carried until an addressed store left nothing to consolidate.
- **Reflection summaries as the default write path** — the experiment shows reflection maximizes raw recall but loses the exact keywords fact lookups need. It is not the per-turn mechanism, and the consolidation output it was otherwise available as no longer exists.
