## Kestrel Export Feature Implementation

### Complete Implementation

```python
"""
Kestrel Export Module
Provides CSV export functionality following the Quartz contract.
"""

import csv
import io


def render_export(rows):
    """
    Render export rows to CSV text.
    
    Args:
        rows: Iterable of (label, count) tuples
        
    Returns:
        CSV formatted string
    """
    output = io.StringIO()
    writer = csv.writer(output)
    
    # Header following Quartz contract
    writer.writerow(['label', 'total'])
    
    # Write data rows
    for label, count in rows:
        writer.writerow([label, count])
    
    return output.getvalue()


def validate_export(rows, schema):
    """
    Validate export data against Quartz contract schema.
    
    Args:
        rows: Data rows to validate
        schema: Expected schema definition
        
    Returns:
        tuple: (is_valid, errors)
    """
    errors = []
    
    for idx, (label, count) in enumerate(rows):
        if not isinstance(label, str):
            errors.append(f"Row {idx}: label must be string")
        if not isinstance(count, (int, float)):
            errors.append(f"Row {idx}: count must be numeric")
    
    return (len(errors) == 0, errors)
```

### Example Output

```python
# Sample data
inventory = [
```
